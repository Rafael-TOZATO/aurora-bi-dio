## 📊 Principais Indicadores Financeiros (Validados)

* **Receita Bruta:** US$ 127.931.598,50
* **Receita Líquida:** US$ 118.726.350,26
* **Lucro Total:** US$ 16,89 mi (com margem de lucro de **14,2%** sobre a receita líquida)
* **Unidades Vendidas:** 1.125.806 unidades (1,13 mi)
* **Período de Análise:** Setembro de 2013 a Dezembro de 2014 (5 países)
